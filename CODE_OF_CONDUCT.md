# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, criticize code and ideas rather than
people, and keep the space welcoming for everyone regardless of background or
experience.

To report unacceptable behavior, contact the maintainer privately through
their GitHub profile. Reports are handled confidentially.
